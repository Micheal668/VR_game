БЫСТРЫЙ ЗАПУСК — РЕКОМЕНДУЕМЫЙ СПОСОБ

1. Полностью распакуйте ZIP. Не открывайте проект прямо из архива.
2. Откройте Unity Hub → Projects → Add (Add project from disk).
3. Укажите папку VR_Labs_1_2 — именно ту, в которой лежат Assets,
   Packages и ProjectSettings. Папку Assets отдельно выбирать не надо.
4. Используйте Unity 6000.6.1f1 — это версия вашего присланного проекта.
   При первом открытии дождитесь импорта файлов и установки пакетов.
   Если пакеты ещё не закешированы на компьютере, нужен доступ к Unity Registry.
5. В Unity откройте сверху меню VR Labs → Open scenes и выберите
   свою фамилию и лабораторную. Либо дважды нажмите нужный .unity
   в Project → Assets → VRLabs → Scenes.
6. Нажмите Play. Для остановки нажмите Play ещё раз.

Готовые сцены уже входят в папку. Нажимать Prepare missing scenes
при обычном запуске не требуется. Эта команда восстанавливает
отсутствующие сцены; существующие не перезаписывает.

ЧТО ЗАМЕНЯТЬ В СТАРОМ ПРОЕКТЕ

При рекомендуемом способе выше ничего заменять не нужно.

Если обязательно хотите сохранить старое расположение проекта:
1. Закройте Unity. Сделайте копию всей старой папки проекта.
2. Перенесите старые Assets, Packages и ProjectSettings в резервную
   папку СНАРУЖИ проекта. Не оставляйте резервную Assets внутри Assets.
3. Скопируйте из этого архива папки Assets, Packages и ProjectSettings
   целиком в корень старого проекта.
4. Откройте этот корень в Unity Hub версией 6000.6.1f1.

Важно: простое объединение папок оставит старые скрипты Samples 2.6.5.
Здесь используется установленный у вас XR Interaction Toolkit 3.6.0;
старые демонстрационные скрипты из Samples исключены. Поэтому при
замене переносите три папки целиком, а не только отдельные .cs.
Все .meta-файлы копируются вместе с соответствующими файлами.

В этой папке сохранена исходная Assets/Scenes/VR Scene.unity.
Это резервная старая сцена, а не готовая лабораторная для сдачи.
Открывайте новые сцены из Assets/VRLabs/Scenes.

ЗАПУСК В АУДИТОРИИ С HTC VIVE

1. Подключите и включите шлем, контроллеры и базовые станции.
2. Откройте SteamVR. Дождитесь обнаружения шлема и обоих контроллеров.
3. Проверьте, что активной средой OpenXR назначен SteamVR
   (настройки SteamVR → OpenXR; расположение пункта зависит от версии).
4. На Windows выберите профиль сборки Windows/Standalone.
5. В Edit → Project Settings → XR Plug-in Management для PC
   должен быть включён OpenXR и Initialize XR on Startup.
   В OpenXR → Enabled Interaction Profiles включён HTC Vive Controller Profile.
   Эти проектные настройки перенесены из вашего исходного проекта.
6. Откройте свою сцену, нажмите Play и наденьте шлем.
   Подключайте шлем до запуска Play: режим управления определяется при старте.

Ось высоты настроена относительно пола (Floor). Рост уже входит в
данные шлема. Не добавляйте к этой высоте ещё 1.65 м вручную.
Если на кафедре установлена другая версия Unity, не подтверждайте
случайное понижение версии: сначала установите 6000.6.1f1 или используйте
отдельную копию для переноса. Эти файлы не заявлены как совместимые с 2022.3.

УПРАВЛЕНИЕ В ОЧКАХ

ЛР1: осмотр, движение головы и двух контроллеров. Синим шариком показан
левый контроллер, жёлтым — правый. На сцене есть куб, шар, цилиндр,
цветной пол и фамилия конкретного студента.

ЛР2:
• Левый трекпад — движение относительно направления взгляда.
• Правый трекпад — поворот. Изначально включены шаги по 30°.
• Боковая кнопка Grip слева — прямое взятие рядом с предметом.
  Отпустите Grip, чтобы отпустить предмет.
• Боковая кнопка Grip справа — выбор/захват предмета правым лучом.
• Удерживая предмет лучом, верх/низ правого трекпада меняет расстояние
  до предмета. На это время поворот игрока приостанавливается.
• Триггер справа — нажатие кнопок UI и перетаскивание слайдера.
• «Сменить поворот» переключает плавный и ступенчатый режим.
• «Начать заново» перезагружает текущую сцену и возвращает исчезнувший
  или разбитый шар, удаляет созданные копии и закрывает дверь.

Что показать в общей части ЛР2:
1. Перемещение и поворот в обоих режимах.
2. Столкновение с кубами/стенами при движении трекпадом.
3. Подбор синего куба левой рукой, отпускание на стол/пол.
4. Подбор того же куба правым лучом и изменение расстояния трекпадом.
5. Слайдер на панели действительно меняет яркость света.
6. Дверь: подойти, поднести левую руку к жёлтой ручке, зажать Grip,
   потянуть ручку. Hinge Joint ограничивает ход до 120 градусов.
7. Правый луч + Grip на оранжевой капсуле создаёт цилиндр.

ИНДИВИДУАЛЬНЫЕ ЗАДАНИЯ ЛР2

Вариант 1: жёлтый куб на отдельной тумбе. Навести правый луч и нажать
Grip — справа появляется шар. Повторное отпускание/нажатие создаёт
ещё один шар. Прямой захват левой рукой не должен срабатывать.

Вариант 2: жёлтый шар на тумбе. Правый луч + Grip — шар исчезает.
Левая рука не должна его активировать. Чтобы повторить, нажмите
«Начать заново» на панели правым лучом и триггером.

Вариант 20: жёлтый шар на тумбе. Поднести левый контроллер к шару
и нажать Grip — исходный шар исчезает, появляются восемь небольших
физических сфер. Правый луч не должен активировать этот объект.
Мелкие сферы можно подбирать. Для повторения — «Начать заново».

Это именно нажатие захвата рядом с объектом, а не одно касание без Grip.
Событие Select Entered соответствует прямому взаимодействию из методички.

ПРОВЕРКА ДОМА БЕЗ ОЧКОВ

Нажмите Play, затем щёлкните по вкладке Game, чтобы она получала ввод.
Если работающий XR-дисплей не обнаружен, включится управление:
• WASD — движение;
• удерживать правую кнопку мыши и двигать мышь — смотреть вокруг;
• левая кнопка мыши — правый луч, нажатие предметов и UI;
• пробел — захват левой рукой;
• колесо мыши — вытянуть/приблизить левую руку.

Для варианта 20 подойдите так, чтобы синий шарик левой руки пересекался
с жёлтым шаром, и нажмите пробел. Если не дотягиваетесь — колесо мыши.
Для двери так же наведите синий шарик на ручку, зажмите пробел
и двигайтесь/поворачивайтесь, чтобы потянуть ручку.

Режим без очков проверяет логику и сцену; он не заменяет проверку
на реальном HTC Vive. Плавный и ступенчатый поворот сравнивайте в шлеме:
в режиме без очков обзор задаёт мышь.

ГДЕ СМОТРЕТЬ НАСТРОЙКИ ДЛЯ ЗАЩИТЫ

• XR Origin (XR Rig): камера, Camera Offset, Character Controller,
  Character Controller Driver (в ЛР2).
• XR Origin → Camera Offset → Left Controller → Direct Interactor:
  XR Direct Interactor, trigger-сфера, маски Interactable + Only Direct.
• XR Origin → Camera Offset → Right Controller → Ray Interactor:
  XR Ray Interactor, линия, маски Interactable + Only Ray.
• Variant N - Individual Task: XR Simple Interactable и Lab Variant Action.
  В Select Entered есть вызов LabVariantAction.OnSelected.
• Interactable Door → Door - Hinge Joint: XR Grab Interactable,
  Rigidbody, Hinge Joint; в списке выбираемых коллайдеров только ручка.
• XR UI Canvas: World Space Canvas, Tracked Device Graphic Raycaster.
• EventSystem: XR UI Input Module.
• Lab Settings - Student Name: фамилия, группа и номер лабораторной.

У подбираемых предметов коллайдер НЕ Trigger: иначе они будут
проваливаться сквозь пол. Trigger включён у области захвата левой руки.
Названия legacy-компонентов движения и контроллеров оставлены как
в методичке; они поддерживаются в закреплённом XRI 3.6.0.

ПРОВЕРКА ПЕРЕДАННЫХ ФАЙЛОВ

Проверены структура шести сцен, внутренние ссылки fileID и GUID,
связи событий, маски Ray/Direct, подписи, настройки контроллеров,
состав UI, дверной шарнир и синтаксис добавленных C#-скриптов.
API XR сверены с исходниками пакетов XRI 3.6.0 и Core Utils 2.6.0.
Компиляция и Play Mode в Unity, а также запуск на HTC Vive в среде
подготовки недоступны и не выполнялись. Это исходный Unity-проект,
а не проверенная на вашем оборудовании исполняемая сборка.

Если есть красные ошибки Console: сначала дождитесь установки пакетов
и убедитесь в версии Unity. Не открывайте старую VR Scene для сдачи.
Сообщения OpenXR о том, что дома нет устройства/runtime, отличаются
от ошибок компиляции C#. Для проверки в очках сначала запустите SteamVR.
