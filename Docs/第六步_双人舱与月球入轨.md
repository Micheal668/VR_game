# 第六步：双人舱、凹凸月面与月球入轨

当前主场景是 `Assets/_LunarEscape/Scenes/09_LunarStation_Orbit.unity`。Unity 菜单 **Lunar Escape → Open Orbital Flight Scene** 可直接打开；旧的 04–08 教学场景仍保留。

维修 → 警报 → 选择物资 → 沿路标走到梯子前 → 点击梯旁大按钮 → 进入双人舱 → 启动 → 垂直离地 → 平滑转弯 → 观察基地爆炸、处理损伤 → 高空爬升 → 点击入轨修正 → 稳定月球轨道。

## 怎样试玩

1. 打开 09 场景，点击 Unity 顶部 Play。按原流程开始任务、维修并等待警报。
2. 选择最多 3 类物资，沿青色路标前进，绕到梯子前的青色登舱区。走进区域不会自动登舱。
3. 平视梯子旁的大按钮，点击“点击登舱 / 进入双人上升器”。旧舱门按钮仍可使用。登舱时自动固定手持和包内物资；只有当前玩家身体进入登舱区才能确认。
4. 闭眼转场后进入左侧玩家操作位，右侧是指挥官 NPC 的独立舱位。舱内固定身体，保留头部观察、手柄指向和按钮操作。
5. 顺序点击 **接通电源 → 导航检查 → 发动机准备 → 点火**。导航、发动机检查各 2 秒，点火 3 秒。基地倒计时始终继续。
6. 升空先垂直离地，再逐渐倾斜。看左侧窗外的基地和月面，观察爆炸；按实际损伤使用物资。
7. 爆炸后的检查结束，飞船继续爬升。面板显示高度、速度和倾斜角。到达“入轨窗口”时点击 **执行入轨修正**，推进 6 秒后完成本阶段。
8. 稳定轨道显示约 **100 km / 1.63 km/s**。此时冻结本阶段资源消耗，可观察窗外月球或点击重新开始。

Mac 模拟器保持原有鼠标及头部/手柄模式操作。身体模式 WASD 行走，Q/E 不会让身体飞起来。登舱后无需用 WASD 驾驶飞船；这一步采用程序飞行，玩家负责启动、资源处置和最后的入轨确认。

## 这次改了什么

| 试玩问题 | 09 场景的处理 |
|---|---|
| 顶部舱门难点中 | 梯旁增加平视的大按钮，登舱区扩大到约 5.2×5.2 m，并给出可登舱提示。合法点击锁存确认，下一帧小幅走出区域不会卡住；超时仍优先失败。 |
| 月面像一块平板 | 用真实高度网格制作坑底、坑缘、丘陵和远山。近景有 MeshCollider，基地、路线与着陆区做平整处理。飞行近景复用同一地形网格。 |
| 起飞后没有后续飞行 | 连续轨迹串起垂直离地、转弯、爆炸观察、高空爬升和入轨窗口，再加入 6 秒入轨修正及稳定轨道状态。 |
| 舱内只能容纳一个人 | 舱内扩大至约 4.4×4.8 m，舱高 3.15 m，左右操作位间距约 2 m；加入约 1.8 m 高的指挥官角色、脚台、靠背和扶手。外观横向放宽 18%，总高仍约 7 m。 |

登舱区域围绕梯子，不允许在基地远程上船；仍有实体舱体碰撞。真实月面近景网格覆盖约 192×160 m，远景覆盖约 1.6×1.6 km，可行走边界仍限制在基地与登舱路线附近。没有制作整颗可探索月球。

## 时间、物资与失败

- 飞行时间经过压缩，离地到入轨窗口约 **80–128 秒**，会随登舱时剩余倒计时变化；最后的入轨修正另需 6 秒。为了看清基地爆炸，低空段保留爆炸后的观察时间，再继续高空爬升。
- 双人舱供氧仪表以整舱可用秒数计，09 初始为 **180 秒**，容量 **240 秒**。NPC 暂不拥有独立耗氧、生命或任务结局；没有在旧耗氧基础上再隐式扣一遍。
- 启动耗电及持续耗电沿用第五步，入轨修正额外消耗 **2 点电量**。到达窗口后等待仍消耗资源；推进中资源耗尽也会失败，不能跳过失败直接成功。
- 早起飞避开损伤；较晚起飞可能漏气、受伤和掉电。止漏、医疗、补氧、补电仍消耗实际携带物资。严重损伤后仅恢复生命不一定够，后续爬升还要有电量和氧气。
- 重开会恢复玩家、地面场景、物资、飞行仪表、入轨按钮及窗外状态，并保留当前语言。

## 这一步的范围

按本轮确认，指挥官先作为**可见同乘 NPC + 独立舱位**出现。当前是固定站姿，不包含跟随、对话、月面救援或 NPC 生死分支；救援剧情以后接入。

飞行采用平滑的预设轨迹和简化的入轨判定。100 km 处的圆轨道速度按月球二体公式计算，但面板速度不是压缩动画位移的导数，也没有模拟真实推力、燃料、六自由度或轨道积分。当前终点为稳定轨道；会合、手动对接和完整评分属于后续步骤。

月球远景使用 NASA LRO 月球表面纹理与球形网格，约 0.9–3 km 高度间从局部地形渐变到球形月球。爬升中段叠加程序陨石坑光照细节，高空缓慢展示侧倾使地平线留在侧窗视野。制作参数和来源见 [双人舱与月球素材来源](双人舱与月球素材来源.md)。Mac 自动验证与实际画面记录见 [验证记录](验证记录.md)，真实 VIVE 设备验收尚未完成。
