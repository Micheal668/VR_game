# 飞行场景素材来源

- 月面全景图：通过 Codex **内置 image_gen 工具**生成，未使用 CLI/API fallback。用于远处月面曲面背景，不是 NASA 实拍，也不表示精确登月地点。
- 工程文件：`Assets/_LunarEscape/Art/Flight/LunarPanorama.png`，2172 × 724 像素。原始生成图直接复制进入工程，没有用脚本修改图片。
- 爆炸闪光、颗粒形状和淡入淡出：项目中的程序化 Shader 与网格动画；少量远处碎片为简单 3D 模型。
- 船体冲击音：`HullImpact.wav`，由 `BuildAscentScene` 使用固定种子噪声与低频波形合成，不含外部录音。
