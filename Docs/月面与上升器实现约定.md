# 月面与上升器实现约定

**当前路线：真实近景月面 + 连续全球远景 + 双人舱 + 程序上升 + 手动对接。** 最新主场景为 `10_LunarStation_Docking`，操作见 [第七步说明](第七步_连续月面与手动对接.md)。

基地撤离 → 月面路线 → 梯旁登舱 → 双人舱启动 → 垂直离地与平滑转弯 → 观察基地爆炸与处置损伤 → 入轨修正 → 手动接近 → 辅助锁定 → 对接结算。

| 部分 | 制作约定 |
|---|---|
| 月面与路线 | 陨石坑、坑缘和丘陵使用真实高度网格。近景约 192×160 m，远景约 1.6×1.6 km；基地、着陆区与撤离路平整处理。基地中心到着陆器约 48 m，可行走范围仍限于基地和登舱路线附近。 |
| 登舱 | 梯旁平视大按钮和原舱门共用规则；身体到青色区域后主动点击。舱体碰撞继续生效，走近不会自动上船。合法确认后锁存，下一帧小幅移动不会卡住，截止时间仍优先判失败。 |
| 地面外观 | 10 主场景使用用户提供模型与照片制作的 Blender 修订版，导入为原生 FBX、URP 材质和 Prefab。舱门、舷梯和支脚碰撞按模型定位；08、09 保留原教学模型。 |
| 基地与道具 | 10 主场景的基地内外按原布局重新建模，接入网上获取的写实工具、物资和设备及项目自制电池；沿用现有任务、抓取、门与身体碰撞规则，08、09 保持教学原貌。来源、修改、尺寸和性能统计见 [基地与道具模型来源](基地与道具模型来源.md)。 |
| 双人舱 | 舱内约 4.4×4.8 m，舱高 3.15 m，玩家和指挥官 NPC 各有独立操作位。外观横向放宽 18%，总高仍约 7 m；这些是游戏布局参数，不是阿波罗工程尺寸复刻。 |
| NPC 范围 | v0.2 接入约 1.8 m 指挥官的受困、实体救援、固定路线跟随、医疗及真实登舱判定。基地维修影响初始伤势；被留下、伤势或飞行事故会影响结局。沿用原套装，无腿部行走动画、自由寻路或复杂对话。 |
| 升空与入轨 | 先垂直离地再平滑转弯，沿同一任务时钟进入爆炸观察和爬升；到达入轨窗口仍需主动执行 6 秒修正。高度与速度仪表、资源消耗、失败和重开由同一规则层判定。 |
| 窗外近景与高空 | 近景复用基地和真实地形，全球曲面直接接续远景边界，使用同一材质和球面坐标。高空等比缩放外景保持观察连续；环绕纹理速度可调，不建设整颗可探索月球。 |
| 飞行真实性 | 上升采用时间压缩的连续预设轨迹，第 3 秒不停止，姿态由曲线切线确定；高空观察姿态含展示调整。对接积分相对速度和姿态并扣主燃料/RCS，不模拟完整轨道动力学。 |
| 爆炸 | 沿用原始倒计时和离地余量分档损伤；使用闪光、月尘/碎片和声音，不制作整座基地的物理破坏。 |
| VR 舒适度 | 登舱后固定身体和游戏内移动，保留头手追踪、按钮操作与舱内参照物。爆炸轻微晃动舱体及外景，幅度随撤离余量分档；不改写头显姿态，画面震动可关闭。 |
| 重力与时间 | 月面物理采用向下 **1.62 m/s²**，释放速度按手部实际速度；不改变 `Time.timeScale`。10 的供氧以整舱剩余秒数计，初始 420 s；指挥官独立计量生命和伤势，不再额外扣整舱氧气。救援与伤势由原任务的实际时间步推进。 |
| 阶段结算与后续 | 已有基础救援和月面撤离至对接的10000分结算，真实记录三人结果。返航再入、随机事故导演、更多救援分支、远距离轨道会合及轨道器内部仍待后续实现。 |

月球参数依据 [NASA 月球参数表](https://nssdc.gsfc.nasa.gov/planetary/factsheet/moonfact.html)。素材署名、转换及修改见 [登月舱模型来源](登月舱模型来源.md) 和 [双人舱与月球素材来源](双人舱与月球素材来源.md)。

当前范围继续以课程原型和可验证的小步为准。普通平面视频不能代替可交互近景；增加几何与远景效果后，双眼显示、近处视差、文本清晰度、帧率和舒适性都需在学校 Windows + VIVE 设备上验证。
