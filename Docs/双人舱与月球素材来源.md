# 双人舱与月球素材来源

09 场景的地形为工程内程序生成的真实网格，陨石坑、噪声丘陵、基地与路线平整区参数在 `LunarTerrainProfile.cs` 中。它是课程场景，不对应具体月球着陆点。

## 指挥官模型

- 来源：[NASA Astronaut](https://science.nasa.gov/3d-resources/astronaut/)，页面署名 **DigitalSpace Corporation**。
- [原始 Astronaut.glb](https://assets.science.nasa.gov/content/dam/science/cds/3d/resources/model/astronaut/Astronaut.glb)，保存于 `Assets/_LunarEscape/Art/Crew/`。
- SHA-256：`d18c141410542b935113d1c25a9271d90c40d44015a64295b7b68a30f0ce2820`。
- 2 组材质、6,381 个三角形；转换到 Unity 原生静态网格，缩放至约 1.8 m 高。原始 PNG 纹理保留。舱内实例使用单独烘焙的双臂下垂姿态；原始展示网格和 GLB 保留。
- 原模型无本项目可直接使用的骨骼动画，当前角色固定在右侧操作位。不是已完成的 NPC 跟随或救援系统。

转换仍使用项目内 `Tools/convert_apollo_lm.py` 与 `Editor/ImportApolloModel.cs`，新增了源目录、文件名、来源链接和署名参数。生成结果随工程提供，正常在 Windows 打开无需额外 Python 或模型插件。

## 月球远景

- 来源：[NASA Scientific Visualization Studio — CGI Moon Kit](https://svs.gsfc.nasa.gov/4720)，**NASA's Scientific Visualization Studio / Ernie Wright / LRO LROC**。
- [LRO 2019 4K 月球颜色纹理](https://svs.gsfc.nasa.gov/vis/a000000/a004700/a004720/lroc_color_poles_4k.tif)，保存在 `Assets/_LunarEscape/Art/Orbit/lroc_color_poles_4k.tif`；下载后的原图未改写。
- SHA-256：`918649a7f8ed2f1329b2cd95bb0d25483befdcb60ae1a66db681a637cc21344f`。
- 中近距离叠加两级程序陨石坑法线光照，减少全月球纹理在爬升时被放大后显得平坦的问题；这些细节不对应真实着陆点，也不是 LRO 高程数据或新增可行走碰撞。
- 高空使用球形网格和原图，在渲染坐标中缩小 100 倍以保持深度精度；仪表仍使用真实量纲的公里与公里/秒。材质中调整光照和颜色，不把影像当作可行走月面。
- 月球平均半径约 1,737.4 km、重力参数约 4,900 km³/s²，数值依据 [NASA 月球参数表](https://nssdc.gsfc.nasa.gov/planetary/factsheet/moonfact.html)。圆轨道速度使用 `sqrt(μ / (R + h))`，在 100 km 高度约 1.633 km/s。

NASA 发布素材不表示 NASA 对本项目的认可或参与。原始来源与校验元数据另存于 `Art/Crew/source.json` 与 `Art/Orbit/sources.json`。上升器外观仍使用 [登月舱模型来源](登月舱模型来源.md) 中记录的 Apollo 模型；09 为双人游戏舱做横向加宽，不能当作历史飞船尺寸复刻。

## 10 场景：连续月面与轨道器

继续使用上述 NASA 原图与 NPC 素材，未新增外部模型。全球曲面由 `BuildContinuousMoon` 沿现有地形边界生成，近处加入同源高度场与程序大坑，远处渐变为月球曲面；同一材质以球面坐标采样原始颜色纹理。远景程序细节和着陆区均不对应真实地理高程。整套外景围绕观察点连续缩放到 0.01–1 倍，保持角尺寸；替代 09 中独立球体渐显的方式。

等待对接的轨道器由 `BuildDockingScene` 在项目内生成船体、太阳能板、天线、接口和导航灯。它是原创几何原型，不是特定真实型号的工程复刻。月表纹理运动表现环绕时的相对运动，默认 0.12 度/秒可调，不表示月球真实自转。
