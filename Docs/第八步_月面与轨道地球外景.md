# 第八步：月面与轨道地球、星空外景

当前场景仍为 `Assets/_LunarEscape/Scenes/10_LunarStation_Docking.unity`。

在月面向基地的 +Z 方向抬头约 18° 可看到地球；登舱、升空、入轨和手动对接继续使用同一天空。默认轨道姿态下，地球位于前舷窗上方偏右的天空中。舱壁、窗框、月面与轨道器会正常遮挡天空。

素材是用户提供的 `VR项目照片/从月球看地球 .png`，原样复制到 `Assets/_LunarEscape/Art/Orbit/Earthrise.png`。渲染时只采样照片里的地球部分并压低黑背景噪点，不显示照片底部的月面，不重新生成地球影像。未核实该照片的原始拍摄者和授权信息。

星空使用用户提供的 `VR项目照片/星空2.png`，原样复制到 `Assets/_LunarEscape/Art/Orbit/Starfield.png`。月面、升空和轨道均可看到这张稀疏星空照片，地球的圆盘（包含暗面）遮挡背后的星空。照片按经纬环绕，背面边缘柔和混合、极点渐暗；它不是原生 360° 全景，也不表示真实星图。纹理启用多级缩小和三线性过滤，减少转头时细小星点的闪烁。

在 `Assets/_LunarEscape/Materials/Earth Sky.mat` 材质中调整 **Star field brightness** 可改变星空亮度，默认 `0.65`；设为 `0` 可恢复黑色背景。星空和地球一起响应飞船姿态，玩家转头时不会跟着视野移动。

Hierarchy 中选择 **Earth Sky**，在 **Earth Sky View** 组件调整：

- **Ground Direction**：地球在月面坐标中的方向；默认 `(0, 0.32, 1)`。
- **Angular Diameter**：地球的视直径；默认 6°，为便于课程演示识别而作视觉放大，并非真实天文比例。

地球以天空渲染，忽略玩家平移和外景距离缩放；玩家转头时会自然离开视野。飞行时跟随现有月球外景的旋转，体现上升转弯和 RCS 姿态变化。月表纹理的展示滚动不会让地球跟着旋转。重新开始恢复月面方向。

菜单 **Lunar Escape → Add Earth to Docking Scene** 可以重新应用资源和引用；主场景重建入口也包含此步骤。旧版 04–09 教学场景继续保留。

这是远景照片展示，不包含地球自转、昼夜实时变化、真实地月星历或绕月背面遮挡的完整轨道模拟。
