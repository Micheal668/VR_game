# 基地与道具模型来源

本次升级用于 `Assets/_LunarEscape/Scenes/10_LunarStation_Docking.unity` 的基地外部、可玩室内、维修工作台和物资架。`08_LunarStation_Ascent`、`09_LunarStation_Orbit` 保留原教学外观。基地按照现有游戏布局重新建模，是月面科研站的游戏设计，不是现存月球基地的扫描，也不是某个已建成基地的工程复刻。

来源、作者、下载文件与校验值以以下清单为准：

- [下载来源清单](../Models/LunarBase/Downloads/source-manifest.json)：网页、作者、许可、原始尺寸、文件下载地址、MD5/SHA-256；各资源目录还有独立 `source-manifest.json`。
- [道具导出清单](../Assets/_LunarEscape/Art/StationProps/material-manifest.json)：8 项资源的修改说明、导出尺寸、三角形数、贴图通道和 FBX SHA-256；各导出目录还有独立 `provenance.json`。
- [基地导出清单](../Assets/_LunarEscape/Art/LunarBaseGeometry/base-manifest.json)：材质、米制定位点、隐藏的旧渲染对象、导出网格和三角形统计。

## 基地模型

基地外壳、保温层、连接舱、结构环、太阳能板、通信天线、舱内壁板、设备柜、灯具、工作台和货架由项目在 Blender 中制作。作者为 Lunar Escape 项目；几何、程序生成的表面贴图与项目标识属于本次项目自制内容，未将其标为第三方下载素材或 CC0 素材。

可编辑源文件是 [LunarStation_Realistic.blend](../Models/LunarBase/LunarStation_Realistic.blend)。Unity 使用 [LunarStationExterior.fbx](../Assets/_LunarEscape/Art/LunarBaseGeometry/LunarStationExterior.fbx) 和 [LunarStationInterior.fbx](../Assets/_LunarEscape/Art/LunarBaseGeometry/LunarStationInterior.fbx)，分别包含 30、18 个网格，共 **48 个网格、183,072 个三角形**。导出按材质及空间分组合并，可编辑源文件保留独立部件。

布局沿用 8 × 8 m 的主房间、地板表面 Y = 0、约 3.3 m 的净高及原撤离通道。关键 Unity 定位点包括气闸门 `(4, 1.25, 1.7)`、通道出口 `(8.1, 0, 1.7)`、维修接触点 `(0.58, 1.22, 0.49)` 和货架台面 `(0, 0.92, 3.1)`。建模脚本将 Unity XYZ 转换为 Blender `(X, -Z, Y)`；Unity 导入根据轴向定位点烘焙坐标并核对这些位置，不依赖模型包围盒猜测朝向。

## 制作与 Unity 接入

以下脚本名称已与仓库文件核对。保留现有下载清单及原始文件后，可按需要重新生成资源：

1. [fetch_station_assets.py](../Tools/fetch_station_assets.py)：通过 Poly Haven 公开 API 下载上述六项 2K 模型/贴图，检查文件 MD5，记录 SHA-256 与作者、许可、尺寸。该脚本不负责 NASA 模型下载；月岩原始 ZIP、解包内容和来源记录保存在 `Models/LunarBase/Downloads/apollo_10021_79/`。
2. [build_lunar_base_blender.py](../Tools/build_lunar_base_blender.py)：在 Blender 中生成可编辑基地、纹理、定位点、内外 FBX 和基地清单。
3. [prepare_station_props.py](../Tools/prepare_station_props.py)：在 Blender 中准备六项 Poly Haven 道具，烘焙姿态、保留 UV、提取氧气瓶、转换贴图并导出 FBX。
4. [prepare_lunar_sample.py](../Tools/prepare_lunar_sample.py)：读取已解包的 NASA OBJ，减面、保留 UV、缩放贴图、放大游戏副本并导出。
5. [build_industrial_battery.py](../Tools/build_industrial_battery.py)：在 Blender 中制作原创电池、1K 聚合物贴图、可编辑源文件及 FBX，并更新清单。
6. Unity 入口为 [BuildRealisticStation.Install](../Assets/_LunarEscape/Editor/BuildRealisticStation.cs)，菜单 **Lunar Escape → Install Realistic Lunar Station**。入口先导入基地及道具材质/预制体，再打开并保存主场景 10。查看菜单为 **Lunar Escape → View Realistic Lunar Station**。

Poly Haven 道具保留 2K 底色、OpenGL 切线法线和 AO。原 ARM 的 B 通道写入 Unity 金属度 R 通道，`1 - roughness` 写入平滑度 alpha；底色按 sRGB 导入，法线、金属度/平滑度和 AO 使用线性数据。电路板 alpha 材质采用裁切。NASA 月岩仅使用源颜色贴图与游戏材质常量；自制电池采用程序生成的 1K 表面贴图。

主场景保留 **7 件动态物资与 1 件维修工具**：氧气瓶 2 件，维修箱、电池、医疗盒、数据核心、月岩各 1 件，另有维修扳手。每个原交互根下增加 `Realistic Prop` 可见子树，复用原 `CargoItem`、`Rigidbody`、`XRGrabInteractable` 和复位逻辑；视觉子树不添加碰撞体或刚体。简单碰撞包络及货架上的出生高度按最终模型调整，避免扁盒、电路板悬空或穿台。

物资配额保持最多 3 类、总重 12 kg，氧气最多 2 件、其余每类 1 件；质量仍为氧气 3 kg、维修箱 4 kg、电池 4 kg、医疗盒 2 kg、数据核心 1 kg、月岩 5 kg。这些是游戏规则，不能据此推断模型代表实物的质量。维修工具类型、工具头检测、任务计时、门开关、身体通道、登舱及失败重开继续使用现有交互系统。

基地可见根为 `Station Realistic Exterior` 和 `Station Realistic Interior`；原房间与通道的碰撞和传送组件保留，旧块体渲染隐藏。飞行中的 `Distant Base` 保留原根引用，只复制需要显示的外观网格，复用网格及材质，避免把室内物资或交互脚本复制到远景。地面气闸门继续由现有阶段逻辑控制；爆炸和下次飞行的基地远景复位继续由 `LunarWindowAnimation` 管理。

## 性能统计与验证范围

当前清单统计为：基地 **183,072 三角形**，8 项道具资源各计一次合计 **90,233 三角形**。这是导出资源统计，不是当前画面每帧提交量；双氧气瓶、重复设备和飞行代理有实例复用。共享网格/材质可避免重复资产，但并非 LOD，本轮没有制作距离分级模型。后续导出有变化时，应重新读取清单统计，不能沿用固定估算。

[StationArtSceneTests.cs](../Assets/_LunarEscape/Tests/PlayMode/StationArtSceneTests.cs) 的 3 项主场景集成测试与 2 项既有登月舱/对接回归已实际运行通过：**5 Passed、0 Failed**，最终结果见 [station-tests-final.xml](../Logs/station-tests-final.xml)，运行时间为 2026-10-07 03:04:38–03:04:41 UTC。覆盖模型与材质引用、代理网格复用、无多余道具碰撞、货架稳定、真实 XR 扳手抓取维修、气闸开启后的身体通路、物资抓放/收纳/丢弃、登舱、升空入轨、手动接近/辅助对接、基地爆炸及重开恢复。

美术截图 `Docs/Previews/station-exterior.png`、`station-interior.png`、`station-supplies.png` 和 `station-workbench.png` 使用独立查看相机，并临时隐藏 Canvas、玩家身体与随身腰包的渲染，便于检查模型；截图结束会恢复全部状态，不改变真实游戏显示。另输出 `Docs/Previews/station-gameplay.png`：从实际 MainCamera 的位置、旋转和视场拍摄，保留 UI 与正常第一人称身体显示，用于核对真实游戏视图。以上五张截图均来自最终测试运行，并已人工检查模型朝向、铭牌文字、表面材质和第一人称显示。

VR 真机性能尚未测量。双眼帧率、近距离细节、贴图清晰度、抓取手感和舒适性仍需在目标 Windows + VIVE 设备上验证。
