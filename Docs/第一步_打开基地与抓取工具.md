# 第一步：进入基地，拿起维修工具

## 这一步做什么

认识 Scene（场景，也就是一个关卡的物体集合）、Game（游戏摄像机看到的画面）、Hierarchy（当前场景的物体列表）和 Inspector（选中物体的属性面板）。完成“看见房间 → 拿起工具 → 放手”这一个练习。

当前是基础交互原型，尚未制作氧气故障、撤离、爆炸和评分。墙上的英文是临时界面文字，不代表最终游戏语言。

## 1. 打开工程和场景

1. 打开 Unity Hub → 项目 → 添加 → 从磁盘添加项目，选择本文件上两级的 `LunarEscapeVR` 文件夹。
2. 使用 **6000.6.1f1** 打开。第一次导入需要等待，底部进度结束后再操作。
3. 在 Unity 顶部菜单选择 **Lunar Escape → Open Foundation Scene**。也可以在 Project（项目资源面板）中打开 `Assets/_LunarEscape/Scenes/04_LunarStation_Foundation.unity`。

完成标准：Hierarchy 中能看到 Station Room、XR Origin、XR Interaction Manager、XR Interaction Simulator 和 Maintenance Tool。

XR Origin 是玩家的根对象，包含头部摄像机和左右手；XR Interaction Manager 负责把手柄与可交互物体联系起来。

## 2. 运行并环顾房间

点击编辑器顶部的三角形 **Play**，然后点击 Game 画面，让它接收键盘输入。

场景中使用 Unity 官方 **XR Interaction Simulator**（用键盘鼠标模拟头显和手柄），并通过自有 `CollisionAwareSimulator` 接入玩家碰撞。屏幕显示当前模式和按键提示；按 `Tab` 在第一人称与设备操作模式间切换。第一人称或 `H` 头部模式下，`W/A/S/D` 沿地面行走，墙和桌子会挡住身体；`Q/E` 不会让身体升降。第一人称模式用鼠标右键切换视角控制。切到手柄模式后，`Q/E` 仍可上下移动手柄。此键鼠方式只是开发工具，真实头显的默认移动方案是传送和分段转向。

完成标准：看见基地墙壁、桌子、青色维修工具和墙上任务提示，能够环顾。

## 3. 抓取并放手

本机已验证的最简方法：在 Game 画面中用鼠标点击桌上的工具进行点选抓取，再点一次释放。观察墙上提示变化。

需要练习直接操控设备时：按 `]` 选择右手柄或 `[` 选择左手柄。设备模式下用鼠标与移动按键调整手柄，对准桌上的维修工具，按住 `G` 模拟握持，松开 `G` 放手。`T` 模拟扳机。优先对照屏幕模拟器提示确认当前模式与活动设备。

完成标准：

- 抓住后工具跟随手，墙上提示变为 **TOOL ACQUIRED**。
- 松开后工具受到物理作用，提示变为 **GRAB + RELEASE COMPLETE**。
- 再次点击 Play 退出运行。练习状态会重置，这一阶段没有存档。

若窗口不响应，先点击 Game 面板并确认输入法为英文。不要在 Play 模式下修改并期待自动永久保存场景。

## 学校 VIVE Pro Eye 真机验证（后续在 Windows 完成）

本机只有 Mac，以下步骤尚未真机验证：

1. Windows 安装相同完整版本的 Unity，准备 Windows Build Support 模块。通过 SteamVR 确认头显、两只手柄和基站已识别，完成实验室规定的房间设置。
2. SteamVR 作为当前 OpenXR 运行环境。OpenXR 是游戏连接不同 VR 设备的统一接口。
3. Unity → Edit → Project Settings → XR Plug-in Management，桌面平台启用 OpenXR；在 OpenXR 的 Enabled Interaction Profiles 中加入 **HTC Vive Controller Profile**。本阶段只安装了相关包，尚未在 Mac 上启用 Windows 运行配置。
4. 运行前停用场景的 XR Interaction Simulator 对象。它带有 EditorOnly 标签，正常构建时不会包含到最终游戏；但在 Windows 编辑器里接头显运行仍要手动停用。
5. 如果学校使用标准 VIVE 棒状手柄，验证侧面握持按钮、扳机和圆形触控板；如果配的是其他手柄，按实际型号调整交互配置。
6. 验证头部跟随、双手定位、抓放、传送、分段转向，并检查丢失追踪后的恢复。目标为匹配设备 90 Hz 的稳定表现，必须在学校电脑实测，Mac 模拟结果不能代替。

## 先读哪段代码

先读 `Assets/_LunarEscape/Scripts/Interaction/ToolPractice.cs`。其中 `Awake` 取得抓取组件，`OnEnable` 注册抓取事件，`OnGrabbed` 和 `OnReleased` 修改提示，`OnDisable` 取消事件监听。中文注释解释了这样做的原因。

`ReturnFallenTool.cs` 只负责把掉出地板的工具放回桌面。`Editor/BuildFoundation.cs` 是初次搭场景的辅助脚本，不是游戏每一帧都执行的逻辑。

当前项目重力已设为向下 **1.62 m/s²**，基础、维修和撤离三个场景一致。工具从静止位置释放会比地球上慢落；理想情况下下落 1 米约需 **1.11 秒**。手部带有速度时，工具仍会继承释放速度；重量和质量不是用来降低下落加速度的参数。任务倒计时与输入没有放慢。
