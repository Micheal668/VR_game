# 第四步：物资取舍与月面登舱

**维修 → 最终警报 → 选择物资 → 穿过小范围月面 → 进入上升器 → 确认登舱、清点物资**

本课承接第三步，落实你确认的“小范围真实月面 + 可交互舱内 + 简化窗外景观”。完成只表示登舱；启动、升空、基地爆炸与评分将在下一步继续接入。

## 打开并运行

Unity 菜单选择 **Lunar Escape → Open Cargo and Boarding Scene**，点击 **Play**。对应场景为 `Assets/_LunarEscape/Scenes/07_LunarStation_CargoBoarding.unity`。04、05、06 仍可独立打开。

只想检查新玩法时，可在 Play 中选择 **Lunar Escape → Preview Cargo Evacuation (Play Mode)**。它会重开并快进到 60 秒撤离阶段，方便测试物资与路线；不修改任务时长。

按 `H` 切到头部模式，用鼠标点“开始演练”。维修和上一课相同：工具头有效接触 2 秒，成功后等待 4 秒进入警报；修好有 90 秒撤离，未修好有 60 秒撤离。维修窗口仍为 90 秒。

## 选物资，放进物资包

物资架在维修台后面的墙边。**只有最终警报开始后才允许拿取物资**，可以在警报前先认识摆放位置。当前有六类，氧气瓶有两件，其余各一件。

| 物资 | 数量上限 | 单件重量 |
|---|---:|---:|
| 氧气瓶 | 2 | 3 kg |
| 维修包 | 1 | 4 kg |
| 应急电池 | 1 | 4 kg |
| 医疗包 | 1 | 2 kg |
| 数据模块 | 1 | 1 kg |
| 月壤样本箱 | 1 | 5 kg |

**最多 3 类，最多 12 kg。** 重量是这一版用于测试取舍的游戏参数，不代表真实航天物品。比如“氧气瓶 ×2 + 维修包 ×1 + 数据模块 ×1”是 3 类、11 kg，可以携带；已经有 3 类时，再拿第 4 类会被拒绝。

**抓取 → 移到腰前青色物资包里 → 松手收纳。** 放在包外松手就是丢弃，物品仍会按月球重力掉落，可以重新捡起。收纳后的物资从手中消失，清单保留数量。资源架、腰前和舱内的清单都显示同一份携带内容；“丢弃 1 件”会把已收纳的那件物品放回玩家前方。

Mac 模拟器：`]` / `[` 选择右 / 左手，`G` 模拟握持，手柄模式下 `W/A/S/D` 与 `Q/E` 调整位置；`H` 返回身体模式，`W/A/S/D` 行走。切回 `H` 后可用普通鼠标点界面按钮。用英文输入法，`Y` 可查看模拟器提示。

手持、物资包、已装进舱内的物资**共用额度**，装船不会腾出额外类别。丢完某一类才释放它的类别名额。拿取、收纳与路上犹豫都不会暂停倒计时。

这一版先验证选择、携带、丢弃和回收清单；氧气补给、维修包消耗、医疗救人、电池供电及科研评分尚未接入。因此不会把“背包里有氧气瓶”直接表述为生命保障已经延长。

## 沿月面进入上升器

从右侧打开的门出去，经过原来的通道，再沿青色路标走过约 12 米的月面路线。脚下是实体地面，护栏和边界会挡住身体，窗外岩石和远山只是有限范围的背景。当前约 30 × 30 米的地面是本版模型尺寸，不是后续必须固定的地图规格。

走进上升器，站到舱内青色区域，再点 **“确认登舱 · 收好物资”**。这会固定当前随身物资、关闭舱门并结束本段撤离。走到旧通道末端、伸手入舱、把物品扔进去，或站在外面点按钮，都不会完成任务。允许空手撤离，物资不是登舱的强制门票。

确认前倒计时一直继续；撤离时间归零仍是死亡结算，只能重新开始。重试会清空携带记录、把物品放回原架、把玩家送回起点，保留当前语言。

舱内有真实窗洞和窗框，可以观察外面的月面。当前没有点火、升空动画、基地爆炸、轨道运动或对接；画面中的“本阶段完成”不表示全游戏通关。

## 参数与代码

停止 Play 后，在 Project 中选 `Assets/_LunarEscape/Settings/Evacuation Cargo.asset`，查看类别数、总重量和每类数量/重量。任务时长仍在 `Station Mission.asset`。月面重力保持 **1.62 m/s²**，没有把整个游戏放慢。

| 组件 | 通俗理解 |
|---|---|
| `CargoInventory` | 唯一的物资账本，检查能不能拿、能不能收和怎么清零 |
| `CargoItem` / `CargoPackZone` | 连接真实抓取与“在包里松手”的动作 |
| `CargoPresenter` | 显示同一份账本，提供丢弃按钮 |
| `CargoBoardingController` | 身体在舱内才允许确认，不替代任务倒计时 |
| `LunarRouteAccess` | 按任务阶段开放室外传送，登舱后关门 |
| `BuildCargoBoardingScene` / `BuildLunarSurface` | 编辑器生成可继续修改的场景模型与连接 |

Mac 编辑器验证结果见 [验证记录](验证记录.md)。学校 Windows + VIVE 的手柄收纳手感、舱内文字清晰度、舒适性和帧率仍需真机检查。
