# 第九步：乘员模型与键盘移动

主场景：`Assets/_LunarEscape/Scenes/10_LunarStation_Docking.unity`。

## 键盘操作

点击 Unity 的 Play，再点击 Game 游戏画面和开始按钮。W/A/S/D 分别向前、向左、向后、向右移动。在手柄操作模式下也保留行走；Q/E 仍上下移动手柄。鼠标转动镜头及既有拾取交互继续使用原来的输入。

登舱和失败结算会按原流程锁定身体移动，重试后恢复。移动沿视线的水平投影进行，通过玩家碰撞系统，不能穿过墙壁和工作台。

## 航天服

原始文件为用户提供的 `VR项目照片/Advanced Crew Escape Suit.glb`，副本保存在 `Assets/_LunarEscape/Art/CrewEscape`。原文件未修改，作者与授权信息未在文件中明确提供。

源模型没有骨骼与动画。项目创建了原生 Unity 网格、材质及简化上身骨架，NPC 使用原始站姿；玩家身体跟随头部水平位置，双臂根据两只手柄位置估算肘部。第一人称隐藏自身头盔，保留 NPC 头盔。旧手柄外观隐藏，交互组件和追踪对象保留。没有新增外观碰撞体。

当前不含腿部行走动画、手指抓握动画或真实全身追踪。模型跟随效果属于三点追踪估算，需要后续戴头显校准舒适度和手部朝向。模型与移动修改仅接入当前主场景，历史教学场景保留原样。

## 资源维护

`BuildCrewSuit` 从保留的网格缓存生成材质、网格和 Prefab。菜单 `Lunar Escape > Install Crew Escape Suit` 将资源接入主场景；脚本 `Rebuild` 可重新生成蒙皮并保留已有资源标识。重建主对接场景时也自动安装航天服。

原始 GLB 的 Draco 网格使用 `Tools/convert_apollo_lm.py` 解码，来源记录及 SHA-256 存在资源目录的 `source.json`。转换只需在更换原始模型时执行，正常打开 Unity 无需 Python 或 Blender。
