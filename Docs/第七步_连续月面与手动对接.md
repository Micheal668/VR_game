# 第七步：连续月面与手动对接

当前主场景：`Assets/_LunarEscape/Scenes/10_LunarStation_Docking.unity`。

**维修 → 撤离与收纳 → 登舱 → 启动 → 3 秒垂直上升 → 平滑转弯 → 损伤处置 → 入轨修正 → 手动接近 → 辅助对齐 → 接口锁定。**

## 打开与操作

Unity 菜单 **Lunar Escape → Open Rendezvous and Docking Scene**，然后点击 Play。07–09 场景继续保留；本次对接功能在 10 场景内。Mac 使用 Head 模式操作第一人称和鼠标面板；手柄模式用于模拟抓取。开始、维修、撤离与登舱方式沿用前两课。

1. 警报后，把选定物品放入腰前框内再松手，或在框口正上方松手让它落入。成功后实体收起，清单数量增加；可携带类别、数量、重量仍受同一套限制。放在旁边、取消抓取、从未拿过的物品不会被自动收走。
2. 到梯旁点击登舱，依次接通电源、启动导航、准备引擎、点火。前三秒完全垂直上升，第 3 秒仍保持向上速度；随后沿连续弧线倾斜，最终逐渐转为水平。爆炸时间和损伤仍取决于撤离时机。左侧舷窗向下延伸到观察地窗，转弯过程中可低头观察基地。
3. 到达约 100 km 入轨窗口，点击入轨修正，等待 6 秒。前方轨道器在窗口外等待，完成修正后面板切换为 RCS 对接控制。
4. 先用左右、上下和姿态按钮缩小误差，再短按前进建立较小接近速度。**松手只是停止喷气，飞船仍按惯性移动。** 按住“保持制动”让平移和旋转速度降下来，制动也消耗 RCS。
5. 距离约 10 m 时开始减速。进入辅助范围并看到提示后，松开推进按钮，辅助微调位置和姿态，缓慢靠近，最后用 2 秒完成机械锁定。也可以关闭辅助练习手动修正，但最终自动捕获需重新开启辅助。

刚入轨默认距接口约 35 m，存在约 0.69 m 横向偏差和约 3.6° 姿态偏差，玩家需要修正。面板下方显示位置 X/Y 与俯仰、偏航、滚转误差；平移按钮作用于飞船自身方向。对接成功后冻结本轮资源，显示物资使用与带回科学物资数量，可点击重新开始。

## 当前辅助与失败规则

这些数值是课程原型参数，可调；不是实际航天任务的安全标准。

| 条件 | 默认行为 |
|---|---|
| 沿接口轴向距离 ≤8 m、横向偏差 ≤0.8 m、姿态误差 ≤8°、相对速度 ≤0.35 m/s、转速 <2°/s | 开启辅助且松开所有推进按钮后，开始位置/姿态微调 |
| 距接口面约 0.55 m、横向误差 ≤0.18 m、姿态 ≤3°、相对速度 ≤0.12 m/s、转速 ≤1°/s | 进入捕获，2 秒后锁定 |
| 撞到接口时相对速度 >0.5 m/s | 显示撞击爆炸并失败，高速越过接口也会检测 |
| 低速接触但仍未对齐 | 对接口受损，任务失败 |
| 总距离 >140 m、横向偏离 >35 m，或飞过目标后方 | 错过对接机会，失败 |
| RCS 耗尽 | 无法继续控制对接，失败 |
| 供氧、生命或电量耗尽 | 沿用原有失败规则；不会因正在捕获而免除消耗 |

主推加速在 12 m 内禁用，近处使用小推力 RCS。辅助需要满足多个条件，不会从远处直接把飞船拉到接口，也不会补满燃料。

## 燃料与供氧

主燃料与 RCS 都以初始容量百分比显示。当前是可调游戏模型，没有发动机比冲、实际储箱质量或喷嘴热力学计算。

| 资源 | 当前用途 |
|---|---|
| 主燃料初始 100% | 点火 4%；整个上升段累计 60%；入轨修正 8%；正常到达接近阶段约余 28%。额外主推加速消耗 2.2%/s |
| RCS 初始 100% | 平移、姿态调整、制动与辅助均消耗；单轴满平移约 0.55%/s，满姿态调整约 0.275%/s，多轴合用会增加消耗 |
| 整舱初始供氧 420 s，容量上限 600 s | 给新增长度的会合阶段留出操作时间；转场、启动、上升、等待、对接都计时，漏气会额外消耗；NPC 暂不单独计量 |

剩余氧气、维修包、医疗包和电池可在对接面板中继续使用，与上升阶段共享物资清单。

## 你要的调速接口

Hierarchy 找到飞行舱所在的 **Flight Cabin World** 对象，在 **Continuous Moon View** 组件中调整 **Surface Degrees Per Second**：

| 数值 | 效果 |
|---|---|
| `0.12`（默认） | 缓慢移动月表纹理，表现飞船沿轨道飞行 |
| `0` | 暂停纹理运动 |
| `0.3` | 更容易看出环绕运动 |
| 负数 | 反方向移动；范围为 -2 到 +2 度/秒 |

脚本接口：`ContinuousMoonView.SurfaceDegreesPerSecond`。该运动从到达入轨窗口后开始，不推动真实头显或舱内身体。它是可调的环绕展示速度，不表示月球在自然自转；与真实轨道角速度没有强制绑定。

对接难度在 `Assets/_LunarEscape/Settings/Docking Config.asset` 调整，包括初始偏差、RCS 推力/消耗、辅助阈值、撞击阈值与最大偏离范围。10 场景的供氧在 `Rendezvous Flight Config.asset` 调整。

## 月面为什么能接到高空

基地、路线与近处陨石坑使用原有可碰撞三维网格；远处网格从 1.6 km 地形的每个边界顶点继续向外延伸，逐渐包成月球曲面。所有层级使用同一球面纹理坐标与材质，近处保留程序细节，高空显示 NASA 月球影像，没有旧版的“方形地图缩小后露出黑边，再切换另一颗球”的步骤。

高空把整个外景围绕观察点等比缩小，保持其视角大小并改善大坐标渲染精度；基地与月面仍一起变换。为了在舷窗内看清月球，高空姿态含缓慢的展示侧倾。

## 当前边界

轨道器是项目内生成的 3D 几何原型，有船体、太阳能板、接口和指示灯；尚未制作可进入的轨道器内部。NPC 仍是可见同乘角色。上升时间经过压缩，轨道高度/速度仪表与动画时间不是完整动力学解；对接是局部相对运动与简化碰撞规则，不含远距离轨道转移、交会窗口或精细结构碰撞。月面程序山地和陨石坑不对应真实着陆点，也不是 LRO 高程数据。

验证环境为 Mac Unity 编辑器。真实 Windows + VIVE 双眼显示、按钮手感、舒适性和性能仍需上机测试。详细自动测试及实际截图见 [验证记录](验证记录.md)，素材来源见 [双人舱与月球素材来源](双人舱与月球素材来源.md)。
