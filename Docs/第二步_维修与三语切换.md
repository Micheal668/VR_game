# 第二步：拿工具维修，切换中英俄

这一课只做一条流程：**等待维修 → 拿住工具 → 工具头接触维修点 → 维修完成**。中途松手或移开会暂停，重新接触继续；暂定有效接触累计 2 秒，数值可以调整。

## 1. 打开新场景

Unity 顶部菜单选择 **Lunar Escape → Open Repair Scene**，点击 **Play**，再点击 Game 画面使其接收输入。新场景为 `Assets/_LunarEscape/Scenes/05_LunarStation_Repair.unity`；上一课的 Foundation 场景保留作对照。

你应该看见桌上的青色工具、右边氧气设备的橙色维修点，以及默认中文任务面板。面板包含 **中文 / English / Русский** 和“重新练习”按钮。

## 2. 完成一次维修

- 拿起左边的工具，将白色工具头放到右边橙色维修点附近。只有“被拿住的正确工具”才能推进；仅把工具放在点上不会自动维修。
- 持续有效接触约 2 秒，观察进度和颜色。橙色表示等待或暂停，蓝色表示正在维修，绿色表示完成；文字同时说明状态。
- 中途移开或松手，进度保留。点击“重新练习”把任务清零；这不会强制移动正在手中的工具，也不会改变当前语言。

Mac 使用 Unity 官方模拟器及本项目的碰撞适配。`Y` 打开/关闭输入模式提示，`]` 选择右手柄，`[` 选择左手柄，`H` 选择头部，`Tab` 切换第一人称/设备模式。

- **第一人称或头部模式**：`W/A/S/D` 沿地面行走，墙和桌子会挡住身体；`Q/E` 和滚轮不再用于身体飞行。
- **手柄模式**：`W/A/S/D` 和 `Q/E` 移动所选手柄，方向键调整朝向，`G` 模拟握持，`T` 模拟扳机，也支持鼠标点选工具。使用英文输入法。官方提示仍可能列出身体上下移动键，本项目已停用这项飞行操作。

若仍停留在修复前的运行画面，先停止 Play，再重新进入；玩家会回到场景起点。

真实 VIVE 使用手柄抓取并移动工具，接触即维修，本原型无需额外按住扳机。Windows 端仍需按第一课说明配置 OpenXR，并到学校设备验证按键与舒适性。

## 3. 切换语言，再读一份脚本

**Mac 点语言按钮前，先按 `H` 切换到头部模式，再用鼠标点面板。** 可按 `Y` 查看 Head 是否高亮；按 `]` 返回右手柄模式操作工具。官方模拟器在手柄点选模式中会接管鼠标，这时鼠标点击用于模拟手柄输入。

切换三种语言后，任务文字、操作提示、百分比、设备与工具标签都会即时刷新，进度保持不变。语言按钮始终显示各语言自称，方便切回。每次重新进入运行模式默认中文；当前没有跨运行存档。

先读 `Scripts/Repair/TimedRepairTask.cs`，只看这一条关系：

**交互检测给出“能否维修” → 任务累积有效时间 → 发出变化事件 → 界面显示进度。**

| 文件 | 只负责什么 | 后续怎样复用 |
|---|---|---|
| `Repair/TimedRepairTask.cs` | 计时、暂停、完成、重置 | 氧气、电力等维修共用 |
| `Repair/RepairTool.cs` | 工具类型、工具头位置、是否被拿住 | 给不同工具配置自己的工具头 |
| `Repair/RepairContact.cs` | 正确工具是否进入维修范围 | 更换维修点、工具列表、允许范围 |
| `UI/RepairPresenter.cs` | 根据任务状态更新文字、条形进度和颜色 | 增加显示效果不改维修规则 |
| `Localization/LocalizationService.cs` | 读取三语文案、切换当前语言 | 后续任务继续使用同一个场景语言服务 |
| `Localization/LocalizedText.cs` | 把文字组件绑定到文案键 | 新面板配置一个文案键即可 |
| `Simulation/CollisionAwareSimulator.cs` | 让模拟器身体平移经过已有玩家碰撞系统 | 编辑器键鼠测试共用，不调整真实头显姿态 |

这些路径都位于 `Assets/_LunarEscape/Scripts` 下。自写代码使用中文注释，官方 XR 组件保留原样。

## 调整与扩展

停止 Play 后，在 Hierarchy 选择 **Oxygen Repair Station**：`Timed Repair Task` 的 **Duration Seconds** 是所需有效秒数；`Repair Contact` 的 **Contact Radius** 是维修点接受工具头的半径，当前为 0.14 米。它们是原型参数，不是最终平衡数值。

场景里的任务通过明确引用连接，没有全局单例和每帧全场景搜索。将来更换操作方式，只需更换检测组件提供的条件；更换提示文字不影响任务规则。后续报警流程可以监听任务的 `Completed` 事件。

文字集中在 `Assets/_LunarEscape/Localization/repair-texts.json`。每个 key 必须有 zh/en/ru 三项，`{0}` 等占位符保持一致。新增文案后执行 **Lunar Escape → Refresh Multilingual Font**，再运行 PlayMode 测试检查缺字和排版。字体与许可证保存在工程中，复制到 Windows 时一起保留。

目前覆盖文字界面与维修练习。完整氧气资源消耗、倒计时、撤离、队友和评分将在后续小阶段实现。
