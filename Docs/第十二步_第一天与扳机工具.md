# 第十二步：第一天、扳机工具与声音

游戏现在从 **12_LunarStation_DayOne**（第一天）开始，在卧室床上入睡后进入 **11_LunarStation_LifeSupport**（第二天，事故）。

## 第一天：普通班次

没有倒计时，也不会失败。卧室醒来（黑幕淡入、“第一天”标题）→ 大厅墙边握住航天服把手约 2.5 秒穿好 → 走进气闸室按“气闸循环”，气闸关门、泄压约 3 秒后打开外门（回来时走进气闸室再按一次） → 舱外：

- **太阳能板**：任务已移到基地后方四块30°倾斜的大板，基地前方小板已删除。使用气闸工具架上的**压缩氮气枪**，扫过整块板面；扳机越深，气流越强、越远、越宽，吹尘越快，耗气也越快。空了插回工具架慢慢充气。月面真空里水会立刻沸腾结冰，所以用氮气。四块板吹净后指示灯变绿。
- **取芯**：同一工具架上的**取芯钻**。把钻头竖直顶在橙色定位环中心，扳机控制转速：转速在当前地层合适区间（钻上指示灯绿）钻得最快；太慢（琥珀）打滑；太快（红）发热，过热卡钻，松开扳机冷却。越往下越硬。钻到 30 cm 岩芯弹出地面。

三根岩芯带回站内，放到实验室墙上的**月壤分析仪接口**。每根样品分析约18秒，完成后在墙上托架生成一份数据和一罐月壤。取出样品会暂停，再次插入接续进度；同一样品不会重复产出。实验室左侧桌旋转后沿墙摆放，右侧桌已移除，分析仪、模块面板固定在墙上，中央通道可直接走到仪器前。

完成清板和三份样品入仪任务后，回到基地墙架，握住把手约2.5秒归还航天服，再回卧室握住自己的床入睡 → 黑幕“第二天” → 载入场景11。舱外不能归还航天服。

完整任务清单显示在大厅北墙，第一天已取消手腕任务面板。穿服后头盔HUD显示氧气、电量、当前任务及目标方向和距离。地面指挥只在早上与收工时各说一句，其余由指挥官吐槽并顺带提示。

航天服初始氧气和电量均为100%。穿戴时持续耗电，进入无空气环境后消耗内置氧气；挂回墙上后停止消耗。第一天结束时剩余资源原样进入第二天，第二天仍需重新穿服，用准备好的氧气瓶和电池补充。直接启动场景11进行调试时，航天服以100%开始。

第一天配电箱内装有完好保险丝，抓住箱盖即可打开检查；完好的芯不要求拆卸。第二天芯烧坏，打开箱盖、拔出坏芯、拿备用芯插入即可恢复该项供电。

## 两天共用布局与物资准备

制氧机、充电台、实验室分析仪、工具架、维修面板及物资来自同一份场景布局。第一天普通物资各组随机出现1–3件，睡觉切换第二天时不重新抽取；搬动过的物资及工具也保留最终位置。数据和月壤只有实际研究完成后才出现。

- **氧气瓶**：初始为空，放入制氧机旁的圆形接口充氧，约20秒充满。取出即暂停，瓶身显示实际百分比。
- **电池包**：初始为空，放入工程舱充电台接口充电，约20秒充满。氧气和电池接口只接受对应物资。
- **跨天规则**：充装和研究不会在睡眠画面中自动推进。第一天完全没充过的氧气瓶或电池第二天仍为空、不可使用，也不能在第二天开始新的充装。第一天已开始但未充满的可以继续：电池需恢复基地电源，氧气还需修复制氧机。
- **逃生使用**：半满物资按其实际存量补给航天服或飞船；空瓶、空电池不会被消耗。研究完成的数据和月壤可按原有携带额度收进腰包并带上飞船。
- **重试**：第二天重试回到第一天结束时的物资、充装、研究与插槽状态，不重新随机物资。重新开始第一天则开启全新一轮。当前跨天数据保存在本次游戏运行中，未增加退出游戏后的存档。

充装为选做项，不阻止睡觉；未完成的样品分析在第二天恢复供电后可继续。大厅清单显示充氧、充电及分析进度，头盔HUD保留当前任务和服装资源。

物品仍然贴手握持。拿住氧气瓶、电池、岩芯、保险丝或维修模块，瞄准4.5米内对应的空接口，出现绿色连线和放置提示后扣扳机即可放入；瞄准空台面或地面也可放下。错误类型、已占用接口或实体遮挡会阻止放置。第二天瞄准放置目标时，扳机不会同时消耗物资给航天服补给；要补给时，将物品拿在手中并移开接口或台面目标后使用，或通过腕部补给按钮操作。

## 第二天新增：出口钢梁与激光切割器

泄压开门后，出口通道外端被三根坍塌的钢梁堵住。切割器挂在通道南墙支架上。光束很短，要贴近钢梁，沿每根梁两端的**红色切割线**移动光点；扳机深浅即功率，功率越大切得越快，但发热按功率平方增长，满功率几秒就会过热停机。两条线都切开后钢梁倒下，不再阻挡玩家。

## 扳机工具的握持

所有扳机工具使用固定握点、瞬时跟手，并采用“粘手”握持：按一下侧键拿起后松开也不会掉，再按一下侧键放下；扳机只用于工具本身。远距离抓取的物品现在会吸到手上，而不是悬停在射线命中处（`Install Grab Comfort` 菜单）。

## 声音、音乐与细节

- 舱外与泄压后的基地：外界声音经低通滤波变闷；无线电语音和手中工具不受影响。
- 各舱段背景声：大厅与走廊通风、工程舱配电嗡声、实验室仪器声；断电时变得很轻，合闸后恢复。
- 背景音乐用代码合成，只在有空气的基地舱内播放（像站里在放音乐）：第二天醒来与抢修时紧张；第一天平静。出舱、泄压、登船后没有音乐。有人说话时自动压低。
- 卧室、实验室、工程舱和大厅增加了生活与工作细节；舱外四角信标与任务旗；舱顶补光下移减弱；指挥官走路时有起伏和摆臂。

## 安装与验证

场景 11 用朋友的安装脚本重建后，执行 `Lunar Escape > Install Both Days (Voice, Cutter, Polish, Audio, Day One Scene)` 即可补齐第二天内容并重新复制出第一天场景。场景 12 是复制品，不要手工修改。

只安装或更新物资准备功能时，执行 `Lunar Escape > Install Shared Preparation (Both Days)`。该入口先更新场景11的共用工作区，再生成场景12；重复生成保留场景12的资源GUID。

俄罗斯宇航服与胸前鲍曼大学校徽的独立安装入口为 `Lunar Escape > Install Russian Spacesuit and BMSTU Crest (Both Days)`。安装器重建独立外观资源，再更新场景11与场景12；以后生成第一天时也会自动应用这套外观。校徽使用学校官方品牌包中的原始 PNG，原始 SVG 和来源说明保留在 `Assets/_LunarEscape/Art/RussianSuit`。衣架为背包留出空间；服装部件合并到原有蒙皮渲染器，穿脱、隐藏本地头盔、手部追踪及跨天资源规则沿用现有逻辑。

需要重新导入最新太阳能板和实验室模型并更新交互时，执行 `Lunar Escape > Install Station Usability (Both Days)`，再从场景12开始体验。
